# VELMORA — ELåiVA premium e-shop concept

A responsive, single-page storefront concept in Greek. The brand, products, prices and review quotes are fictional and intended only for demonstration.

## Included in the demo
- Responsive premium storefront and category filters
- Product detail modals, demo shopping bag and quantity controls
- Guided scent assistant with scripted sample replies (not connected to an external AI model)
- Demo admin panel to change prices and availability
- Admin changes are saved only in the current browser's localStorage

## Important limitations
- No real checkout, payment processing, order submission, email capture, database or shared inventory is connected.
- The admin panel is a front-end demonstration, not a secure production admin.
- Replace demo images with properly licensed, product-specific photos before any commercial use.
- Do not present the fictional reviews, products or prices as real customer information.

## Deploy on Vercel
1. Open Vercel and choose **Add New → Project**.
2. Import `papastergiouueodwra-hash/velmora-premium-demo` from GitHub.
3. Use the default settings; no build command is required for this static HTML demo.
4. Deploy, then test the generated URL on desktop and mobile before sharing it.
